# Instagram Reel Cover Master System — sitkoalex.ai.business

Status: production specification only. Nothing in this document authorizes public publishing.

## Objective
Make the grid recognizable at a glance while keeping every cover readable on a phone. Use three repeatable families rather than 12 unrelated designs.

## Global rules
- Master canvas: 1080x1920 (9:16); keep the essential title/focal point centered so feed/profile crops remain readable.
- One focal point per cover; no decorative clutter.
- Headline: ideally 3–5 words, maximum two lines, large high-contrast type.
- Keep typography, spacing, portrait treatment and background logic consistent across the launch set.
- Do not place tiny body copy, hashtags, URLs or multiple CTA badges on covers.
- Use the same premium visual language as Highlight covers.
- Export clean 1080x1920 masters without third-party watermarks.

## Family A — FACE + CLAIM
Purpose: positioning, opinion, personal authority, founder-led hooks.
Layout: Alexander/approved portrait as dominant focal point + short claim; restrained premium background; title must remain readable without zoom.
Launch mapping:
- 001: ИИ В РЕАЛЬНОМ БИЗНЕСЕ
- 006: AI НЕ ЛЕЧИТ ХАОС
- 008: 3 ОШИБКИ ВНЕДРЕНИЯ AI
- 012: AI ЗА 30 ДНЕЙ

## Family B — SYSTEM
Purpose: processes, tools, architecture, educational explainers.
Layout: one clean system/object motif + bold title; visual should suggest flow/automation without dense diagrams.
Launch mapping:
- 002: AI-КОМАНДА ДЛЯ БИЗНЕСА
- 004: НЕ ТЕРЯЙ ЗАЯВКИ НОЧЬЮ
- 005: 1 ИДЕЯ = НЕДЕЛЯ КОНТЕНТА
- 007: БИЗНЕС-ПРОЦЕССЫ 24/7
- 009: КАК СЧИТАТЬ ROI ОТ AI
- 010: AI-СИСТЕМА БЕЗ КОДА

## Family C — CASE
Purpose: proof, audits, before/after, conversion assets.
Layout: clear BEFORE → AFTER / diagnostic framing, with evidence taking priority over decoration. Never invent metrics or client results.
Launch mapping:
- 003: ЧТО ОТДАТЬ ИИ ПЕРВЫМ?
- 011: КЕЙС: ДО → ПОСЛЕ

## Grid rhythm
Avoid placing visually identical families three times in a row. Recommended launch rhythm: FACE → SYSTEM → CASE → SYSTEM → SYSTEM → FACE → SYSTEM → FACE → SYSTEM → SYSTEM → CASE → FACE. This gives the grid recurring visual grammar without looking templated.

## Cover QA gate
Before any public approval, verify:
1. Headline readable at profile-grid size.
2. Focal point survives central crop.
3. No unsupported performance/result claim.
4. No watermark or foreign-platform UI.
5. Cover family matches the content promise.
6. Title and first-frame hook tell the same story.
7. No CTA that points to an untested funnel.

## Launch conversion roles
- PIN 1 / 001: FACE + CLAIM — positioning.
- PIN 2 / 003: CASE — diagnostic lead magnet; keep CTA non-transactional until audit intake passes E2E.
- PIN 3 / 011: CASE — proof; evidence-gated.
