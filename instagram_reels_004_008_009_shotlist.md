# Reels production shot-list — 004 / 008 / 009

Status: production draft only. No public publishing approval. All queue items remain `approved=false`; `media_url` must stay empty until final media exists and Alexander explicitly approves publication.

## Global production standard
- Canvas/export: 1080x1920, 9:16, clean original export, no third-party watermark.
- Hook must be visually understandable within first 1–2 seconds even muted.
- Keep critical face, headline and captions away from top/bottom UI zones; verify mobile crop before export.
- Burned-in captions: short phrases, 1–2 lines, synchronized to speech; emphasize only the key noun/number.
- Editing: remove pauses; use pattern interrupts only when they improve comprehension.
- Cover: 3–5 words, one clear idea, same typography family as profile master system.
- CTA must match an actually available next step. Do not promise the AI audit until E2E is live.
