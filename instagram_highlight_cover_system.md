# Instagram Highlight Cover System — sitkoalex.ai.business

Status: PREPARED / NOT PUBLICLY APPLIED
Date: 2026-10-01

Purpose: production master for a coherent premium Highlight navigation system. No Story, Highlight or cover is approved for public posting by this file.

## Master format
- Canvas: 1080x1920 px, 9:16.
- Design primarily for Instagram's circular Highlight crop: all meaningful iconography stays centered in an inner 620x620 px circle around canvas center.
- No essential text near edges. The profile UI supplies the Highlight label below the circle, so the cover itself should use icon/monogram rather than repeat long labels.
- Keep each cover readable at small profile-thumbnail size.

## Visual direction
Premium technology/operator rather than neon "AI hype".
- Base: near-black / graphite neutral field.
- Accent: restrained warm metallic/gold impression to connect with the approved premium portrait; use sparingly.
- Secondary: clean off-white for high-contrast line work when required.
- Avoid gradients that reduce thumbnail clarity, stock robot heads, glowing brains, circuit-board clutter, crypto aesthetics and excessive 3D effects.
- One focal symbol per cover, generous negative space.
- Same line weight, scale and optical centering across the full set.

## Cover family
1. `СТАРТ` — minimal forward arrow / play-path symbol. Meaning: enter here.
2. `КЕЙСЫ` — rising chart with one verified-point marker. Meaning: measured outcome, not fabricated proof.
3. `AI` — simple linked-node / spark mark, not a robot face. Meaning: intelligence connected to process.
4. `ИНСТРУМЕНТЫ` — modular blocks / clean tool-grid mark. Meaning: practical stack.
5. `РАЗБОР` — magnifier over a process node. Meaning: diagnosis. Cover may be prepared now, but Highlight/CTA remains locked until funnel E2E passes.
6. `ОБО МНЕ` — restrained `AS` monogram or silhouette mark. Later-stage navigation.
7. `FAQ` — minimal speech bubble + question mark. Later-stage navigation.

## Typography and labels
- Do not place full Russian Highlight names inside the circular artwork; Instagram's native label carries the title below it.
- If a micro-monogram is needed, use at most 2 characters (`AI`, `AS`).
- Story cards associated with these covers use one consistent sans-serif family, bold display headline, regular supporting text, and 1–2 text sizes per frame.

## Story-to-cover continuity
The Story scripts in `instagram_highlights_story_scripts.md` inherit the same graphite + restrained metallic + off-white visual language.
- Headline: maximum 1–2 lines.
- One idea per Story.
- Real implementation imagery only where available.
- CTA frame visually distinct through spacing/composition, not through extra decoration.

## QA checklist before export
- 1080x1920 master exists.
- Important artwork is fully inside the central circular-safe region.
- Thumbnail remains recognizable at ~80 px.
- No tiny text or duplicate label.
- No invented client/result symbolism that implies unsupported proof.
- All seven covers look like one system when viewed side by side.
- `РАЗБОР` remains visually prepared but operationally locked until E2E pass.

## Publication gate
Creating/exporting these assets is preparation only. Applying covers, publishing Stories, creating public Highlights, or enabling `РАЗБОР` CTA requires the existing explicit public-content approval gates.
